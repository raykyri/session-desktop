# 03 Split flap

Each of the reference's closed petals is opened into its two edges, which no longer meet at the tip: six pairs in total.
Leading edge: r 66→240, 104° sweep, max width 24. Trailing edge: starts 15° behind and further out (r 84→200), 46° sweep, max width 14.
Uses the existing app-icon gradient (#f8d278 → #fa574c) extended into magenta at the tips; the trailing edge is dimmer so the pair reads as a curtain and its echo.
Parameters to tweak: the angular offset between the two edges (controls how open the petal looks) and the trailing edge's sweep.
