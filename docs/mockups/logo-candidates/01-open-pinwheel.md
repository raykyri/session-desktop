# 01 Open pinwheel (round 2: simplified)

Five tapered crescents, each the leading edge of one of the reference's closed petals, with no return stroke.
Each centerline runs from r=70 to r=236 (viewBox 512) while turning 112°, with angle eased by t^1.45.
Width follows t^0.8·(1−t)^1.3, max 46: a fine root, widest about 40% of the way out, a point at the tip.
Color is one gradient per blade: mint to green to cyan to violet at 35% opacity. Glow is 5 px. The mono version uses the same paths.
Parameters to tweak: blade count, sweep, inner radius (size of the hollow center) and the width exponents.
