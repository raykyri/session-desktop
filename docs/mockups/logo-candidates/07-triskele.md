# 07 Triskele (new in round 2)

Three broad blades that each sweep 150°, so every blade wraps nearly halfway around the hollow center.
Centerline r 66→236 with angle eased by t^1.35. Width t^1.0·(1−t)^1.15, max 52, so each blade starts and ends as a point.
One gradient per blade: green to blue to violet at the tip. The mono version uses the same paths and stays recognisable at 16 px.
It has the fewest elements in the set and the boldest silhouette.
