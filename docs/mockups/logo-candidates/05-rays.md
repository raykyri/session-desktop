**05 Rays.** Eight open pinwheel blades, each a bundle of 7 hairline rays, like the vertical striations of an aurora curtain; the bundles start bright mint at a sharp inner edge (the curtain's lower border) and fade through cyan to violet at feathered, uneven tips.
Geometry: every ray is a polar curve with r running linearly from `R_IN`=64 to `R_IN + (R_OUT-R_IN)*frac` (`R_OUT`=226) and theta = blade angle + offset*(pinch→1) + `SWIRL`*u^`BEND` (50°, 1.9), so rays start radial and hook in the rotation direction near the tips; theta depends on absolute radius, so rays in a bundle stay parallel and fan slightly (`BASE_PINCH`=0.35).
Each ray is a filled polygon offset from the curve, width tapering from 3–6.4px at the base to 0.5px at the tip, base snapped to the r=64 circle so the center is a clean empty disc; a per-ray linear gradient (base→tip) carries the color and the opacity falloff, and a blurred copy (stdDeviation 7) adds glow.
Ragged edges come from the per-ray table `(offset°, length frac, base width, intensity)`: lengths 1.00/0.82/0.93/0.70/0.80/0.58/0.66, offsets 0 to −26°. Tweak `BLADES`, `SWIRL`, `BEND`, `R_IN`, and that table.
Mono: each bundle merges into two overlapping tapered strokes (full-length 30px base + 72%-length 26px base, 9° behind), giving one blade with a split tip; legible as a pinwheel at 32px. As a glyph field, density = ray coverage along these polar curves, so the ASCII background can sample the same function.
